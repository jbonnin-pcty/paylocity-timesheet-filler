# Chrome extensions

## Paylocity Timesheet Filler (`timesheet-filler/`)
Fills several days of your Paylocity time card at once, split across cost centers.

**Install (Chrome / Edge):** clone this repository, open `chrome://extensions`, turn on **Developer mode**, click
**Load unpacked** and select the `timesheet-filler` folder.

Before you install, read [`timesheet-filler/PRIVACY.md`](timesheet-filler/PRIVACY.md): it lists exactly what the
extension can access and how to verify that yourself. Usage and details are in
[`timesheet-filler/README.md`](timesheet-filler/README.md). Install from a tagged release and read the diff before
moving to a newer one.
